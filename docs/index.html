Features

主な機能

MetaVisionBOTが提供する、League of Legendsプレイヤーのための統計機能

📊

マッチアップ統計

チャンピオンごとの対面勝率・ピック率・BAN率をMaster以上のソロランクデータから表示。

🏆

高ランクデータ

Master・Grandmaster・Challengerの試合データのみを対象とした、高精度な統計情報を提供。

⚔️

勝率上位ビルド

マッチアップ別の勝率上位アイテムビルドとキーストーンルーンを画像付きで表示。

🎬

動画リンク

マッチアップ参考動画をYouTubeで検索するボタンをワンクリックで提供。

🌐

日英対応

チャンピオン名の日本語・英語両対応のオートコンプリートで、素早くコマンド入力が可能。

🗺️

レーン指定

トップ・ジャングル・ミッド・ADC・サポートのレーンを指定して絞り込んだ統計を確認。

How to Use

使い方

シンプルなスラッシュコマンドでマッチアップ統計をすぐに確認できます

/ lol <チャンピオン名> [レーン]
/lol Yasuo — 全レーンのヤスオのマッチアップ統計を表示
/lol ヤスオ mid — ミッドのヤスオのマッチアップ統計を表示
/lol Jinx adc — ADCのジンクスのマッチアップ統計を表示
/lol ダリウス top — トップのダリウスのマッチアップ統計を表示

チャンピオン名は日本語・英語どちらでも入力可能。オートコンプリートで候補を選択できます。

Privacy Policy

最終更新日 / Last Updated: 2025年1月

1. 収集するデータについて

MetaVisionBOT（以下「本Bot」）は、Riot Games APIを通じて取得した以下の公開試合統計データのみを使用します。

  • チャンピオンID
  • 試合の勝敗結果
  • 使用アイテム情報
  • 使用ルーン情報
  • レーン・ロール情報

2. 収集しないデータ

本BotはDiscordユーザーの個人情報を一切収集・保存しません。具体的には以下のデータは取得・記録しません。

  • Discordのユーザー名・ID・メールアドレス等の個人識別情報
  • 入力されたコマンドの内容・履歴
  • IPアドレス・位置情報その他の端末情報
  • サモナー名・Riot IDその他のゲームアカウント情報

3. データの使用目的

収集した試合統計データは、チャンピオンマッチアップの集計統計を算出する目的のみに使用します。 個々のプレイヤーを特定・追跡する目的には一切使用しません。すべてのデータは匿名の集計値として処理されます。

4. データの保存・管理

取得した統計データはBotの運営に必要な期間のみ保持し、第三者への販売・提供は行いません。 Riot Games APIの利用規約に従い、適切に管理します。

5. 第三者サービス・使用API

本Botは以下の第三者サービスおよびRiot Games APIエンドポイントを使用しています。

  • Riot Games League-V4 API — Master以上のプレイヤーリスト（PUUID）の取得
  • Riot Games Match-V5 API — 試合詳細データ（チャンピオン・勝敗・アイテム・ルーン）の取得
  • Riot Games Data Dragon — チャンピオン名・アイテム画像等の取得
  • Discord API — スラッシュコマンドの提供

取得したPUUID等の個人識別子はデータ収集の処理中のみ使用し、データベースには保存しません。 各サービスのプライバシーポリシーも合わせてご確認ください。

  • Riot Games プライバシーポリシー
  • Discord プライバシーポリシー

6. お問い合わせ

本プライバシーポリシーに関するご質問は、 GitHubのIssueページよりお問い合わせください。
